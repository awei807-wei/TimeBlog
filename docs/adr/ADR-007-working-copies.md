# ADR-007：工作副本与正式内容分离

- 状态：已接受
- 决策：自动保存只更新 `entry_working_copies`；正式保存才更新 `entries`、关系、媒体引用和版本快照。
- 原因：作者编辑公开文章时，匿名访客继续看到上一次正式版本；同时支持多份未命名草稿。
- 后果：同步接口必须带 client draft ID、revision 和幂等语义；恢复工作副本不覆盖正式历史。
- 分类和标签字段保留“未提供”和“显式空数组”的区别：未提供时继承工作副本，传 `[]` 时清空已有关系。标签字段省略时继续按既有规则合并正文 hashtag；一旦显式提供数组，数组内容是权威值，不再从 Markdown 补回 hashtag。
- 持久化撤销接口与内存实现均返回 `entry`，其中包含撤销前工作副本的编辑字段，供编辑器回填。
