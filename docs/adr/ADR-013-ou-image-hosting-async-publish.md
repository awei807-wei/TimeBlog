# ADR-013：OU Image Hosting 异步外部发布

## 状态

已接受，2026-08-13。

## 决策

图片上传完成后，本地媒体卷和 `media://` 标识继续作为规范原件与文档引用。只有启用且通过 `ou_image_hosting_v1` 门禁的图片才排入 PostgreSQL `publish_media` job，由 worker 动态读取并解密图床配置后上传。

外部发布状态独立于本地媒体状态；成功保存远端 id 和稳定公开 URL，失败保留本地原件并允许重试。配置版本写入 job payload，旧配置任务不得使用新 Token 静默执行。相同字节由上游 SHA-256 去重，重复响应视为成功。

本地永久删除与远端回收由 `syncDeletes` 显式控制，默认关闭。开启时只调用上游软回收，不实现永久删除；远端失败时本地原件不删除。关闭时允许本地删除并输出结构化的远端残留日志。

## 理由

- 上传请求不等待第三方网络，编辑器能明确区分本地成功与外部失败。
- 私人附件和非图片始终沿用本地鉴权路径。
- `media://` 不绑定具体 provider，切换或停用图床不需要改写历史 Markdown。
- 本地原件提供可恢复、可导出和可迁移的安全边界。

## 安全约束

Endpoint 必须是 HTTPS `/api/uploads`，禁止凭据、非默认端口、query、fragment、内网解析和跨 origin 重定向。Token 仅加密入库，不进入日志或 API 读取响应。交付 URL 必须同源，并拒绝明确的临时签名参数。
